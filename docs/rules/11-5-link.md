# 11.5 Link

*Part of the [Shardbound rulebook](README.md). Keyword.*

- **11.5.1** Two units are linked by the Link effect (8.11). A unit can only have one link: there are no chains. A unit that is already linked cannot be chosen for a new Link.
- **11.5.2** When a linked unit takes damage (from an attack or a spell), the damage is shared: the unit that was hit takes half, rounded up; the linked unit takes the rest. The transferred share is not shared again.
- **11.5.3** Only damage is shared. Destruction, debuffs, freeze and return to hand are not.
- **11.5.4** The link breaks when either unit leaves the board.

> *Example*: 3 damage to a linked unit: 2 for it, 1 for its partner.
