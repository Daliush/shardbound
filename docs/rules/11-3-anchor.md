# 11.3 Anchor

*Part of the [Shardbound rulebook](README.md). Keyword.*

- **11.3.1** A unit with Anchor is protected from its arrival until the start of its controller's next turn (5.2.1).
- **11.3.2** While protected, it can take damage and debuffs, but nothing can make it leave the board: no destruction, no return to hand, no sacrifice, no death at 0 defense.
- **11.3.3** If an effect tries to make it leave the board, only that part of the effect is ignored; the rest of the card applies normally. A sacrifice still counts as paid.
- **11.3.4** A unit that drops to 0 defense while protected is **doomed**: it stays on the board and can still intercept and attack. If its defense goes back above 0, it is no longer doomed.
- **11.3.5** At the end of the turn during which its protection ended, a doomed unit whose defense is still 0 is destroyed (5.4.3). Since "Turn end" abilities resolve first (5.4.1), an end-of-turn heal can still save it.
- **11.3.6** Once the protection is over, the unit can be destroyed, returned to hand or sacrificed normally again.

> *Example*: I sacrifice my anchored unit to pay for a card. The sacrifice counts as paid, the card applies its effect, and the unit stays on the board.
