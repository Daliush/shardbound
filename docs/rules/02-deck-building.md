# 2. Deck building

*Part of the [Shardbound rulebook](README.md).*

- **2.1** A deck contains exactly 30 cards.
- **2.2** A deck contains cards from a single faction (Ember, Tide or Root) and neutral cards.
- **2.3** A deck contains at most 2 copies of the same card.
- **2.4** Tokens are never part of a deck.
