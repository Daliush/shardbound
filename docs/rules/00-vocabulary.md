# 0. Vocabulary

*Part of the [Shardbound rulebook](README.md).*

| Term | Meaning |
|---|---|
| **HP** | A **player's** hit points. The word is reserved for players. |
| **Defense** | A **unit's** hit points. A unit has a current defense and a max defense. |
| **Ability** | What a card does, in the form *trigger → effect → target*. |
| **Attack ability** | The ability a unit uses to attack. It has a cost in Shards. |
| **Controller** | The player who has the card on their board. |
| **Owner** | The player whose deck contained the card. |
| **Active player** | The player whose turn it is. |
| **Destroy** | Send a card from the board to the graveyard. |
| **Sacrifice** | Destroy one of your own units, as a cost or as an effect. |
| **Die** | Be destroyed or sacrificed. A card returned to hand does not die. |
| **Return to hand** | Send a card from the board back to its owner's hand. |
| **Discard** | Send a card from the **hand** to the graveyard. Never applies to the board. |
| **Token** | A unit created by an effect. It belongs to no deck. |
