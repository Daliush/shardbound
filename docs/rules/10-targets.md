# 10. Targets (closed list)

*Part of the [Shardbound rulebook](README.md).*

- **10.1** Possible targets:
  - one unit: allied, enemy or either;
  - one player: yourself, the opponent or either;
  - all units: allied, enemy or all;
  - a random unit, allied or enemy;
  - the card itself.
- **10.2** The ability's controller chooses the targets when it resolves.
- **10.3** An effect with no valid target does nothing. The other effects of the same ability apply normally.
- **10.4** Relics can only be targeted by the effects that name them, Destroy (8.2) and Return to hand (8.8): one relic, allied, enemy or either.
- **10.5** A spell's targets are all chosen when it is played, before its first effect applies. If a target is no longer valid when its effect applies (for example because an earlier effect of the same spell destroyed it), that effect does nothing (10.3). A spell can be played even if one of its effects has no valid target; that effect does nothing.
- **10.6** Likewise, the targets of a triggered ability or of an echo are all chosen when it starts resolving, in the order its effects are printed. A target that is no longer valid when its effect applies makes that effect do nothing (10.3).
